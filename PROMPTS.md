# Project Development Prompt

## Project Overview

KESTREL Motors is a premium full-stack vehicle marketplace built using the MERN Stack.

The platform allows customers to browse premium vehicles, view detailed specifications, purchase vehicles, and track their orders. Administrators can manage inventory, restock vehicles, and process customer orders through a dedicated admin dashboard.

---

## Design Goals

The application should provide:

- Premium automobile showroom appearance
- Modern dark theme
- Orange accent branding
- Smooth animations
- Responsive design
- Clean typography
- Professional user experience
- Consistent spacing and component styling

---

## User Features

- User Registration
- User Login
- Browse Vehicles
- Search Vehicles
- Filter by Category
- Vehicle Details
- Purchase Vehicle
- View Order History

---

## Admin Features

- Dashboard Overview
- Add Vehicle
- Edit Vehicle
- Delete Vehicle
- Restock Inventory
- Manage Orders
- Update Order Status

## Project Structure

Follow a modular architecture using:

- Components
- Pages
- Layouts
- Hooks
- Services
- Routes
- Utilities
- Context
- Middleware
- Controllers
- Models

---

## Coding Guidelines

- Keep components reusable.
- Use descriptive variable and function names.
- Separate business logic from UI.
- Keep styling consistent using Tailwind utility classes.
- Use async/await for API requests.
- Handle loading, success, and error states.
- Write maintainable and scalable code.

---

## Final Goal

Develop a professional, scalable, responsive, and maintainable vehicle dealership platform with a premium automobile-themed user interface and smooth user experience.
